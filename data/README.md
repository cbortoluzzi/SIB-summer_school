# Data

The dataset comprises a total of 10 species, each with a sample size of 15 individuals. Individuals were selected based on the total number of sequenced bases. 

For all species but the barn owl (_Tyto alba_), we selected 5 individuals from a closely related species (also called sister species) to put into context the population genomic parameters estimated for our target species. For the barn owl, we selected 5 individuals from the same species, but from a population in the Iberia peninsula, as this is the LGM refugial population. 

For all species, we selected, whenever possible, a chromosome-level genome assembly. 

All raw sequencing data and genome assemblies were retrieved from the [European Nucleotide Archive (ENA)](https://www.ebi.ac.uk/ena/browser/home) via a custom python script that makes use of the ENA API. The only exception is represented by the _Bos taurus_ genome assembly, retrieved from [NCBI](https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_002263795.3/) and the _Tyto alba_ genome assembly, retrieved from Zenodo.
